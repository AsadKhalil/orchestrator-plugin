# Where the exercises come from

These six exercises are from Exercism's Python track (MIT License), as chosen for Aider's polyglot benchmark: https://github.com/Aider-AI/polyglot-benchmark, folder `python/exercises/practice`, commit `7e0611e77b54e2dea774cdc0aa00cf9f7ed6144f`, copied on 2026-11-19.

Each folder holds the exercise text (`instructions.md`: `.docs/instructions.md`, followed by `.docs/instructions.append.md` where there is one), the stub the model starts from, and the tests. The solutions (`.meta/`) are not copied. The test script keeps the tests out of the model's folder until the chat is over.
